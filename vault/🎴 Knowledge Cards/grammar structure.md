```
[句子]
├── Subject（主语）            ← 主角
├── Predicate（谓语）          ← 动作部分
│   ├── Verb（动词）
│   ├── Object（宾语）         ← 动作的对象
│   ├── Complement（补语）     ← 补充说明
│   └── Adverbial（状语）      ← 修饰动作的方式/时间/地点/原因等
│       └── Adverbial Clause（状语从句） ← 更复杂的状语结构
├── Attribute（定语）           ← 修饰名词
│   └── Relative Clause（定语从句） ← 通过关系代词修饰名词
```
