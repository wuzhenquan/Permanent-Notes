

# 中文语法术语 vs 英文术语 对照表｜语感与功能角度

| 中文术语  | 字面解释/词源    | 英文术语                   | 英文词源思维/功能定义                | 功能解释（在句中的作用）                   | 是否对应 | 备注                   |
| ----- | ---------- | ---------------------- | -------------------------- | ------------------------------ | ---- | -------------------- |
| 主语    | 句子的主要发出者   | Subject                | sub-（在下）+ ject（抛出）→ 动作的承担者 | 句子的主角，动作的承担者                   | ✅    | 中英语义和功能高度一致          |
| 谓语    | 陈述主语的行为或状态 | Predicate              | praedicare（宣布、断言）          | 陈述动作或状态的动词部分                   | ✅    | 中英一致                 |
| 宾语    | 主语作用的对象    | Object                 | ob-（朝向）+ ject（抛出）→ 动作的接受者  | 动作的对象                          | ✅    | 英语强调受动关系             |
| 定语    | 修饰名词的成分    | Modifier / Attributive | modify = 修改、限定             | 修饰名词、限制其意义                     | ✅    | “Attributive” 更书面化   |
| 状语    | 说明状态、情形的语  | Adverbial              | ad-verb-ial = 类似副词的用法      | 像副词一样，修饰动词或句子，说明时间、地点、方式等      | ⚠️   | 中文强调语义（状态），英文强调功能    |
| 补语    | 补充句意       | Complement             | com-（共同）+ plement（填满）      | 补全句子的语义，常出现在系动词结构等             | ✅    | 英文中有主语补语、宾语补语区分      |
| 从句    | 从属小句       | Clause                 | clausula（小结尾、小单位）          | 有主谓结构但不能独立使用的小句                | ✅    | “从”的语义与 “clause” 很吻合 |
| 名词性从句 | 当名词用的小句    | Noun Clause            |                            | 作主语、宾语、表语、同位语等                 | ✅    | 结构上等价名词              |
| 状语从句  | 作状语用的小句    | Adverbial Clause       |                            | 修饰主句，表示时间、原因、条件、方式、结果等，相当于一个副词 | ✅    | 属于状语的一种结构实现          |
| 定语从句  | 修饰名词的小句    | Relative Clause        | 使用关系代词（who, which 等）引导     | 修饰名词或代词，常用关系代词连接，相当于一个形容词      | ✅    | 中英对齐良好               |
